# 음악 장르 지도

장르 계보도, 앨범 해설, 세계 음악 장르 목록을 담은 한 페이지짜리 사이트입니다. 아티스트와 앨범 검색은 위키백과에서 소개 글을 실시간으로 불러옵니다.

## 사이트 켜기 (GitHub Pages)

1. 저장소의 **Settings → Pages**로 갑니다.
2. **Source**를 `Deploy from a branch`로 두고, **Branch**를 `main`, 폴더를 `/ (root)`로 고른 뒤 **Save**를 누릅니다.
3. 1~2분 뒤 같은 화면 위쪽에 사이트 주소가 나옵니다.

## 불러오는 데이터

| 출처 | 쓰는 곳 | 키 |
|---|---|---|
| [위키백과](https://www.wikipedia.org) | 아티스트·앨범 소개, 하위 장르 해설 | 필요 없음 |
| [Last.fm](https://www.last.fm/api) | 많이 듣는 앨범과 곡, 비슷한 아티스트 | 필요 (선택) |

## Last.fm 연결하기 (선택)

키를 넣지 않아도 사이트는 작동합니다. 넣으면 검색 결과에 '많이 듣는 앨범', '많이 듣는 곡', '비슷한 아티스트'가 추가됩니다.

1. <https://www.last.fm/api/account/create> 에서 무료 API 계정을 만듭니다.
2. 발급된 **API key**를 복사합니다.
3. `index.html`에서 `var LASTFM_KEY="";`를 찾아 따옴표 사이에 키를 넣고 저장합니다.

이 키는 사이트 코드에 그대로 보입니다. 읽기 전용 키라 큰 문제는 없지만, 공개되는 것이 싫다면 넣지 마세요.

## 내용에 대해

- 장르 해설, 역사, 감상 가이드, 앨범 해설은 Claude가 작성했습니다. 기존 평론을 옮긴 것이 아니며, 연도 같은 세부 사실에는 오류가 있을 수 있습니다.
- 위키백과 글은 CC BY-SA 라이선스이며, 화면에 출처 링크가 함께 표시됩니다.
- 앨범 재킷 자리의 검은 사각형은 실제 재킷이 아닙니다.
